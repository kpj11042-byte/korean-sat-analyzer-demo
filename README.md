# 문장 사이를 읽다

국어 지문의 문단별 핵심 내용과 어려운 개념을 쉽게 설명하고, 문장 사이의 논리적 연결을 살펴보도록 만든 독해 도구의 공개 데모입니다.

기존 개인용 도구의 분석 결과를 검토해 구성한 예시를 체험할 수 있습니다.

## 체험 방법

1. 과학·기술 지문 「측정값의 흔들림을 줄이는 방법」과 문단별 핵심 요약·쉬운 풀이를 읽습니다.
2. 강조된 핵심 문장 4개 중 하나를 선택합니다.
3. ‘연결해서 읽기’, ‘개념 구별’, ‘주목할 표현’을 확인합니다.

다른 문장을 선택하면 설명이 바뀝니다. 브라우저에서 핵심 문장 4개의 설명 전환과 Tab 이동, Enter·Space 선택을 확인했습니다. 모바일 너비의 브라우저 화면에서는 각 문단의 원문 아래에 풀이가 이어지는 배치를 확인했습니다. 실제 모바일 기기의 터치 조작은 별도로 검증하지 않았습니다.

## 원문과 쉬운 풀이 예시

**원문**

> 가중치는 평균을 구할 때 각 값이 결과에 영향을 미치는 정도를 뜻한다.

**쉬운 풀이**

> 여러 값을 평균낼 때, 어떤 값을 결과에 더 많이 반영할지 정하는 비중이 가중치입니다. 가중치가 큰 값일수록 평균에 더 큰 영향을 줍니다.

## 독해 기준과 해설 방식

- 문단의 핵심 내용과 개념 설명을 나누어 읽습니다.
- 방법뿐 아니라 효과가 성립하는 조건과 한계를 확인합니다.
- ‘다만’, ‘하지만’, ‘결국’이 앞뒤 내용을 어떻게 연결하는지 살펴봅니다.
- 비슷하게 보이는 현상도 원인과 역할을 구별합니다.
- 해설을 원문과 대조하고, 의미가 달라지거나 근거가 부족한 설명을 보완합니다.

## 개발 과정과 기술

개발자가 독해 기준과 화면 요구사항을 정하고, Codex를 활용해 개인용 도구와 공개 데모를 개발했습니다. 공개용 지문을 마련하고, 기존 도구의 분석 결과를 원문과 대조해 수정·보완했습니다.

데모는 HTML, CSS, JavaScript로 구성했습니다. 개인용 도구의 결과 카드 구조와 `textContent` 기반 출력 방식을 복사해 활용했으며, 모바일 대응과 키보드 조작을 적용했습니다.

## 개인용 도구와 공개 데모

기존 개인용 도구에서는 OpenAI API가 입력 지문과 선택한 분야의 독해 가이드라인, 저장된 해설 예시를 바탕으로 문단 요약·개념 설명·대립 개념 비교·문항 해설을 생성했습니다.

공개 데모는 확정된 지문과 해설을 JavaScript에 포함해 표시합니다. 문장 선택에 따라 준비된 설명을 전환하며, 새 분석을 생성하거나 외부 AI를 호출하지 않습니다. API 키와 개인 학습 데이터는 필요하지 않습니다.

## 로컬 실행

저장소를 내려받은 뒤 `index.html`을 브라우저로 열면 됩니다. 별도 설치나 빌드 과정은 없습니다.
